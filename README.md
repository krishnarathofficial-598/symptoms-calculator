# Symptoms & BMI Calculator

A web-based health utility that provides symptom checking and BMI calculation through a simple, responsive interface.

## Features

- Symptoms-based health condition checker
- BMI calculator
- Home and dashboard pages
- User registration and login
- Express.js backend API
- JSON-based user storage for development
- Responsive HTML and CSS interface
- Railway-compatible backend deployment
- Vercel-compatible frontend deployment

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- CORS
- JSON
